{{appTitle}} is a Minecraft save file inspection tool. The relevant Minecraft documentation can be found here. The source code can be found here.

To begin, click on the upload icon and select a Minecraft world folder. Use the other icons to navigate between different views.

Looking for interesting worlds to explore? HermitCraft provides a world download at the end of every season.

*Mods will not break functionality as long as they do not change the way data is stored in .dat or .mca files. Non-vanilla blocks will not appear on the map.
